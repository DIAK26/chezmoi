## Requirements
Install the following tools before or after applying the config:
---
### 🔧 oh-my-zshZsh framework and plugin manager.```bashsh -c "$(curl -fsSL https://install.ohmyz.sh)"```
---
### 💡 zsh-autosuggestionsFish-style command suggestions as you type.```bashsudo apt install zsh-autosuggestions```
---
### 🎨 zsh-syntax-highlightingReal-time syntax highlighting in your shell.```bashsudo apt install zsh-syntax-highlighting```
---
### 🔍 fzfFuzzy finder for history, files, and more.```bashsudo apt install fzf```
---
### 🐱 bat`cat` replacement with syntax highlighting.```bashsudo apt install bat```> **Debian note:** `bat` may be installed as `batcat`. Check with `which bat` or `which batcat`.
---
### 📂 lsdModern `ls` replacement with icons and colors.```bashsudo apt install lsd```
---
### 🖥️ zellijTerminal multiplexer — a modern tmux alternative.```bashcargo install zellij```
---
### ⚡ zedFast, modern code editor.```bashcurl -f https://zed.dev/install.sh | sh```
